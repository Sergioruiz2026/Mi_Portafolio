# Portafolio – Sergio Ruiz Espinoza

Portafolio hecho con React y Vite.

## Ejecutar en tu computador

```bash
npm install
npm run dev
```

Abre la dirección que aparece en la terminal (normalmente http://localhost:5173).

## Editar el contenido

Todo el texto (proyectos, trayectoria, habilidades y contacto) está en `src/data.js`.
Para agregar un proyecto, copia uno de los bloques de `proyectos` y cambia sus datos.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En vercel.com/new importa el repositorio. Vercel detecta Vite solo.
3. Pulsa Deploy.

La foto y el CV en PDF están en la carpeta `public/`.
